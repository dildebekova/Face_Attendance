# Проверка обновлённой поставки
Дата проверки: 2026-11-02.

## Реальные нейросети — выполнено
Установлено отдельное Python 3.12 окружение; `pip check` — нет несовместимых зависимостей.
Загружены настоящие веса из официальных источников. Программа `backend/smoke_models.py` успешно выполнилась без подмены моделей.

- SCRFD: на статическом изображении из scikit-image найдено одно лицо.
- ArcFace через ONNX Runtime CPU: получен embedding из 512 значений, повторная обработка того же кадра дала cosine similarity 1.0. Это тест повторяемости, не показатель точности.
- MediaPipe: обнаружены ориентиры лица.
- MiniFASNetV2: выполнена реальная обработка, оценка класса live — 0.836, ниже начального порога 0.85. Это не тест физической атаки фотографией.
- Пустое изображение отклонено.
- Полная программа smoke-test, включая загрузку моделей: 9.45 с; один диагностический кадр: 320 мс в этой среде. Это не скорость на ноутбуке пользователя.

Машиночитаемый результат: MODEL_TEST_RESULTS.json.

## Сервер и интерфейс
- Production-сборка TypeScript/Vite прошла после добавления выбора камеры и диагностики.
- 6 автоматических тестов политик/API прошли. В этих тестах vision подменена, чтобы независимо проверить бизнес-логику.
- Отдельно FastAPI ASGI TestClient вызвал **настоящие** модели: health=200, camera-check вернул лицо/embedding/landmarks/PAD.
- Проверка последовательности из статического изображения отклонена (422, лицо слишком маленькое); посещаемость не записана. Это не доказательство защиты от фото или видео.
- Без ключа API отвечает 401.
- Uvicorn успешно стартовал. Отдельные процессы среды не разделяют доступ к его localhost; сетевой end-to-end тест не завершён, проверка API выполнена внутри ASGI-процесса.
- Страница входа визуально проверена в браузере. Внутренние экраны после подключения реального backend не проверены браузером.

Результат вызовов API: HTTP_TEST_RESULTS.json. Тестовая БД — временная SQLite.
